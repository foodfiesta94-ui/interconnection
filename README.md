# Inter Connection Study Abroad

A polished, responsive website for Inter Connection Study Abroad.

## Services featured

- Education abroad counselling and applications
- Student visa guidance
- Education loan support
- Value-added and pre-departure services

## Development

This is a lightweight static website. Open `index.html` locally or serve the
directory with any static web server.

## Deployment

The website is deployed to GitHub Pages automatically from the `main` branch
using the workflow in `.github/workflows/deploy-pages.yml`.
